# ATELIER / AUTO DETAILING

Русскоязычная портфолио-концепция премиального детейлинга. Десять смысловых разделов, семь услуг, кинематографичный первый экран, редакционная композиция в сером, индекс девяти разделов в закреплённом хеддере без hamburger menu, история процесса, галерея с фильтрацией и просмотром, интерактивный сценарий обслуживания и форма.

## Запуск

Нужен Node.js 22+. Зависимостей и сборки нет.

```powershell
node server.mjs
```

Откройте http://127.0.0.1:4173. Проверки: `node --test tests/*.test.mjs`, `node --check app.js`. `package.json` также предоставляет start/test/check.

## Взаимодействия

Статичные заголовки и асимметричный первый экран; краткое раскрытие фотографии, направленная смена кадров услуг; закреплённый индикатор этапов работы; контактный лист галереи с выделением выбранного снимка; чек выбранной услуги в форме. Индекс разделов встроен в хеддер и подчёркивает текущую секцию. Плавающей панели, дополнительного курсора, магнитного движения кнопок и декоративного сканирования нет.

Навигация раскрывается в доступном native dialog, меняет фотографию при наведении или фокусе. Escape закрывает окно и возвращает фокус. На мобильном экране панель раскрывается снизу. Услуги доступны по адресам `#service-polish`, `#service-ceramic`, `#service-ppf`, `#service-interior`, `#service-clean`, `#service-restore`, `#service-complete`; клавиши стрелок/Home/End переключают вкладки.

Системный prefers-reduced-motion и переключатель в подвале отключают декоративное движение. Все тексты остаются доступными. Без JavaScript доступны основная структура, тексты и фото; интерактивная форма отключена.

## Приём заявок

По умолчанию форма работает в **деморежиме**: проверяет данные и прямо сообщает, что заявка не отправлена. Данные не сохраняются в localStorage и не передаются в сеть.

Для реального бизнеса задайте `BOOKING_ENDPOINT` в `config.js`: HTTPS API с POST JSON `{name, phone, car, service, comment}`. Успех должен возвращать HTTP 2xx и JSON `{"success":true}` только после сохранения заявки. Ошибки и тайм-аут сохраняют заполненные поля. Сервер должен валидировать данные, ограничивать частоту запросов и длину полей, применять CORS для вашего домена. Не храните секретные CRM-ключи в frontend. Перед запуском добавьте реальную политику обработки персональных данных и согласие в соответствии с требованиями владельца бизнеса. При включении endpoint демотекст автоматически меняется.

## Данные владельца

Замените рабочее название, добавьте подтверждённые контакты, адрес, цены, фотографии выполненных работ, сертификации и реквизиты. До этого нет вымышленных отзывов, бизнес-статистики, карт и LocalBusiness schema. Аналитику подключайте после выбора сервиса и настройки согласий; переменная в config.js оставлена как место интеграции, код аналитики по умолчанию не загружается.

## Публикация

Статические файлы подходят для GitHub Pages. Скрипт `publish.ps1` создаёт отдельный публичный репозиторий и включает Pages из main, если публикация ещё не выполнена. Требуется авторизованный GitHub CLI. Публикуется только этот проект; соседние проекты и оригиналы фото не загружаются.

Использованы навыки brainstorming, writing-plans, executing-plans, sites (локальный статический workflow), test-driven-development, computer-use, systematic-debugging, requesting-code-review и verification-before-completion; Node test runner, Python Pillow, Google Images, web research, браузерная проверка и Git/GitHub API.
